    These clients call the two shared model proxies directly and leave no Claude Code or Codex transcript in the sources above, so they can't be split by repository.     Cross-check: transcripts vs. proxy logs

    For agents whose traffic goes through the proxies, the two independent measurements should agree over the window both cover. Transcripts can run higher where a machine also calls a provider directly (for example the desktop Claude app or Codex signed in to OpenAI).
