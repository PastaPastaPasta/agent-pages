Rust Dash node program

What this program is

An agent team is building rdashd, a Rust Dash full node that must agree with Dash Core bit for bit on consensus. The work spans two repositories, each with a local fork, plus the desktop wallet:

rust-dashcore → node/integration

The node itself: consensus, storage, P2P, evo/LLMQ, RPC, wallet and tooling, plus 40 new crates. Finished tasks land in numbered merge trains.

base-sdk → node/base-sdk

The building blocks underneath: types, transactions, P2P messages, chain parameters and BLS, made to read bytes exactly as Core does. Pieces go upstream to kwvg as small PRs.

dash-desktop is the desktop wallet the same program staffs: DashPay plus masternodes and governance on macOS, Linux and Windows.
