Rust Dash node program: overview

Snapshot 2026-10-31 22:29Z. One view of both forks the rust-dashcore agent runs: what's done, what's moving, and how far each fork is from upstream. Security-sensitive work is left out.

The rust-dashcore agent manages a team of agents building rdashd, a Rust Dash full node that agrees with Dash Core bit for bit on consensus. The work spans two repositories, each with a local fork:

rust-dashcore → node/integration

The node itself: consensus, storage, P2P, evo/LLMQ, RPC, wallet and tooling, plus 40 new crates. Finished tasks land in numbered merge trains.

base-sdk → node/base-sdk

The building blocks underneath: types, transactions, P2P messages, chain parameters and BLS, made to read bytes exactly as Core does. Pieces go upstream to kwvg as small PRs.

The same program also staffs the desktop wallet, dash-desktop: DashPay plus masternodes and governance on macOS, Linux and Windows, landing item by item on its own main.
