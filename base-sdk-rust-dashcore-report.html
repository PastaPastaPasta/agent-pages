Base-sdk work by the rust-dashcore agent

Status snapshot 2026-10-31 ~17:30Z · built from the fork's git history, GitHub, and the program's status, decision and backlog logs

What's going on. The rust-dashcore agent manages a program to build a Rust Dash full node that agrees with Dash Core bit for bit on consensus. That node gets its low-level building blocks from dashpay/base-sdk, kwvg's Rust library of Dash types, transactions, P2P messages, chain parameters and BLS cryptography.

The node needs base-sdk to read every byte the way Dash Core does, including Core's odd edge cases. Waiting for each change to merge upstream would stall the node, so the agent keeps a local fork of base-sdk, lands work there first, and pins the node to it. It then rebuilds small pieces in kwvg's conventions and proposes them upstream as PRs.

This page lists every piece of fork work, what it is for, and how far it has got toward upstream.

Glossary

Core / the reference
Dash Core (dashd), the C++ node. The node program treats it as the definition of correct behaviour.
Decode domain
The exact set of byte strings a parser accepts, and how it reads them. "As Core does" means same accept/reject verdicts, same values, same bytes consumed.
Fork / node/base-sdk
The agent's local base-sdk branch. Nothing node-specific or embargoed goes in it, but it isn't public except a mirror and a preview branch.
Upstream
dashpay/base-sdk's develop branch, maintained by kwvg.
Special transactions
Dash transaction types beyond plain payments: masternode registration and updates (ProTx), coinbase payload (CbTx), quorum commitments, asset locks and unlocks for Platform.
v24
The next Dash Core major release. It changes several special-transaction formats; mainnet signalling starts around 11-09.
Overlay messages
Dash-only P2P messages on top of Bitcoin's: ChainLocks, InstantSend, quorum/DKG traffic, masternode lists, CoinJoin, governance.
LLMQ / DKG
Long-living masternode quorums, and the distributed key generation they run to create a shared BLS key.
BLS legacy vs basic
Dash used a pre-standard BLS encoding ("legacy", via the relic C library) before v19, then the IETF "basic" scheme. Both still appear on chain.
Exotic points
Legacy-encoded BLS values that are not proper group elements but that Core still accepts and computes with. Matching Core here needs a port of relic's arithmetic.
Corpus / vectors
Test cases recorded by running Dash Core itself, so tests check against Core's real answers, not ours.
pkc batch
The next planned upstream PR for the dash-pkc crypto crate.
